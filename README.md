# HTML冒险之旅 - 交互式游戏化教学网站

## 🎯 项目概述

这是一个专为八年级学生设计的交互式游戏化HTML教学网站，将枯燥的编程概念转化为有趣的冒险游戏。学生将通过拖拽、构建、测试等互动方式，循序渐进地掌握网页数据组织的核心知识。

## 🚀 在线体验

**访问地址：** https://lh7hejjoxhwxs.ok.kimi.link

## 📚 教学内容

### 课程结构

1. **第一课：HTML是什么？**
   - HTML基本概念和作用
   - 互动演示：代码与效果对比
   - 知识小测验

2. **第二课：HTML标签大冒险**
   - 拖拽式标签配对游戏
   - 常用标签学习（h1, p, a, img, title, body）
   - 游戏化学习体验

3. **第三课：网页的身体结构**
   - 人体类比教学法
   - 交互式HTML结构构建器
   - 文档结构理解

4. **第四课：超链接的魔法**
   - 超链接创建工坊
   - 链接类型展示
   - 超链接拼图游戏

5. **第五课：实战演练**
   - 项目选择器
   - 实时代码编辑器
   - 完整网页创建

### 评估测试
- **基础挑战**：10题，10分钟
- **进阶挑战**：15题，12分钟  
- **终极挑战**：20题，15分钟

## 🛠️ 技术实现

### 前端技术
- **HTML5**：语义化标签和现代Web标准
- **CSS3**：Flexbox、Grid、动画和渐变
- **JavaScript ES6+**：模块化、异步处理
- **Plotly.js**：数据可视化图表

### 设计特色
- **现代UI设计**：卡片式布局、圆角设计
- **渐变色彩**：紫色到蓝色的科技风格
- **微交互**：悬停效果、点击反馈
- **无障碍设计**：语义化标签、键盘导航

### 数据持久化
- **LocalStorage**：本地存储学习进度
- **JSON格式**：结构化数据存储
- **自动保存**：实时同步学习状态
